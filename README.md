# Тренажер практичних робіт «Інноватика технологічних систем»

Інтерактивний вебтренажер для аспірантів (третій освітньо-науковий рівень, спеціальність G9 «Прикладна механіка», ВНТУ). Містить 7 практичних робіт по 30 варіантів, має автоматичну самоперевірку розрахунків і окремий режим викладача для перевірки та оцінювання.

Тренажер не потребує сервера: це звичайні статичні файли (HTML/CSS/JS), які працюють на GitHub Pages або локально у браузері. Жодні дані нікуди не надсилаються.

## Можливості

**Для аспіранта**
- Вхід за ПІБ, групою та номером у списку. Номер у списку визначає варіант (1–30), а отже й **індивідуальні числові дані**.
- Кожна робота має 5 вкладок: *Завдання* (мета, теорія, формули, контрольні питання), *Робочий аркуш* (структуровані поля, таблиці, кількісний SWOT, реєстр і матриця ризиків), *Розрахунок* (дані варіанта й самоперевірка), *Самоконтроль* (тест), *Здача*.
- Розрахункові блоки за роботами:

| ПР | Що розраховується |
|---|---|
| 1 | Матриця впливів Вестера: A, P, активний / критичний / пасивний елементи; діаграма Вестера; кількісний SWOT з визначенням стратегії |
| 2 | Річний випуск до/після переозброєння (OEE, брак), приріст продуктивності, економічний ефект, термін окупності |
| 3 | Степенева регресія y = a·xᵇ за експериментальними даними: b, ln a, R², прогноз; графік точок і моделі |
| 4 | NPV, PI, IRR, DPP, ROI; таблиця показників «до/після» |
| 5 | Сценарний аналіз: AF, NPV трьох сценаріїв, E[NPV], точка беззбитковості |
| 6 | Поверхня відгуку 2-го порядку: оптимум у кодованих і натуральних одиницях; **віртуальний експеримент** з журналом точок |
| 7 | Мережевий графік (CPM): тривалість, критичний шлях, резерви; кошторис з резервом; діаграма Ганта |

- Автозбереження в браузері, перенесення роботи між комп’ютерами через файл `.json`.
- Звіт із титульним аркушем для друку або збереження в PDF.
- Світла й темна теми, адаптивний дизайн для ноутбука, планшета й телефона.

**Для викладача** (`#/teacher`, PIN за замовчуванням `ITS-2026`)
- Імпорт файлів `.json` від аспірантів, можна перетягнути кілька одночасно.
- Зведена таблиця по групі: оцінка за кожну ПР, бали за модулями (20 + 20 = 40), разом, ECTS-кольори.
- Сторінка роботи аспіранта: **звірка кожного числового результату з еталоном**, кількість спроб самоперевірки, повний робочий аркуш, результати тесту, часові мітки.
- Рекомендована автоматична оцінка (розрахунок 8 + аркуш 8 + тест 4 = 20) з можливістю виставити власну оцінку й коментар.
- Контроль цілісності: позначка, якщо файл редагували поза тренажером або варіант не відповідає номеру у списку.
- Перевірка текстів на схожість між аспірантами (збіг трислівних фрагментів).
- Ключі всіх 30 варіантів кожної роботи з допусками, з друком.
- Експорт відомості в CSV (Excel) і друк відомості.

## Розміщення на GitHub Pages

1. Створіть новий репозиторій на GitHub (наприклад, `its-trainer`).
2. Завантажте в нього **вміст** цієї теки (`index.html`, `assets/`, `README.md`, `.nojekyll`) через *Add file → Upload files*.
3. Відкрийте *Settings → Pages*, у полі *Source* оберіть *Deploy from a branch*, гілку `main` і папку `/ (root)`, натисніть *Save*.
4. Через 1–2 хвилини тренажер стане доступний за адресою
   `https://<ваш-логін>.github.io/its-trainer/`

Посилання для аспірантів: `https://<ваш-логін>.github.io/its-trainer/`
Режим викладача: `https://<ваш-логін>.github.io/its-trainer/#/teacher`

> Локально тренажер теж працює: достатньо відкрити `index.html` у браузері.

## Налаштування (`assets/data.js`, об’єкт `CONFIG`)

| Параметр | Призначення |
|---|---|
| `salt` | «Сіль» генератора даних. Змініть число (напр., на `2027`), і всі числові дані у варіантах стануть новими. Аспіранти, які вже почали роботу, залишаються на своїй солі, бо вона зберігається в їхньому файлі. |
| `teacherPinHash` | Хеш PIN-коду викладача. Новий хеш генерується в режимі викладача → *Налаштування*. |
| `grading.modules` | Розподіл робіт за модулями та бали (за замовчуванням ПР1–4 → 20 б., ПР5–7 → 20 б.). |
| `autoWeights` | Складники автоматичної оцінки (розрахунок / аркуш / тест). |
| `academicYear`, `teacher` | Тексти для звітів і відомостей. |

Тексти робіт, варіантів, теорії й тестових питань також зберігаються в `assets/data.js` і легко редагуються.

## Порядок роботи в групі

1. Аспірант заходить на сайт, вказує ПІБ, групу, номер у списку й отримує варіант.
2. Виконує роботу, перевіряє розрахунок і проходить тест.
3. На вкладці *Здача* натискає «Завантажити файл для викладача» і надсилає `.json` (Moodle / e-mail). Один файл містить усі роботи, тому щоразу треба надсилати найновіший.
4. Викладач імпортує файли, перевіряє роботи, виставляє оцінки, експортує відомість.

База викладача (імпортовані роботи й оцінки) зберігається в браузері викладача. Регулярно робіть резервну копію: *Налаштування → Резервна копія бази*.

## Обмеження безпеки

Сайт статичний, тому PIN і контроль цілісності файлу лише стримують, а не захищають повністю: технічно підготовлений користувач може розібрати код. Тому перевірка викладача **завжди перераховує еталон самостійно** з номера варіанта й не довіряє позначкам «правильно» у файлі. Захист роботи (усні відповіді на контрольні питання) лишається обов’язковим.

## Структура

```
index.html          — оболонка застосунку
assets/data.js      — конфігурація, тексти 7 робіт, 210 варіантів, тести
assets/engine.js    — детермінований генератор даних варіантів і еталонні розв’язки
assets/charts.js    — SVG-графіки (регресія, Вестер, SWOT, грошові потоки, Гант)
assets/app.js       — інтерфейс аспіранта та викладача
assets/styles.css   — дизайн (світла / темна тема)
```
